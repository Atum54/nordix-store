# NORDIX Store

Стартовый интернет-магазин NORDIX на Next.js с каталогом, импортированным из `прайс лист.xlsx`.

## Что уже работает
- Каталог из 37 строк прайс-листа; повторяющиеся позиции сохранены отдельными SKU.
- Встроенные изображения, извлечённые из Excel.
- Поиск и фильтрация по категориям.
- Карточка товара с розничной и оптовыми ценами.
- Автоматический выбор цены по количеству: 1–4 / 5–9 / 10+.
- Корзина с изменением количества и предварительным итогом.
- Переход к оформлению через Telegram.
- Адаптивный премиальный интерфейс.

## Запуск
Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Важно перед публикацией
Это frontend-MVP: корзина хранится в состоянии браузера, а заказ пока передаётся менеджеру через Telegram. Для полноценного запуска подключим базу данных, серверное оформление заказов, управление остатками, авторизацию администратора и проверку актуальности цен. Проверьте изображения, описания и наличие товаров перед публикацией. В Excel две позиции имеют цену по запросу; такие товары отображаются отдельно.

## Источник каталога
`src/lib/products.json` сформирован из строк 3–39 листа «Лист1» исходного Excel. В `sourceRow` сохранён номер строки для сверки.
